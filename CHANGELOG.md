# Changelog

## 1.0.0 — 2026-08-12

- Reproducible synthetic payment pipeline with causal historical features and dataset manifests.
- Explainable investigation priority combining Isolation Forest, deterministic rules, and contextual boosters.
- Human review workflow with alert filtering, case files, account context, relationship graphs, and feedback history.
- Model and data monitoring with artifact provenance, integrity hashes, quality checks, and synthetic evaluation metrics.
- Explicit operational API contracts that exclude evaluation labels.
- Hardened FastAPI and Next.js containers, security automation, dependency audits, and full CI/E2E validation.

All evaluation results in this release were measured on controlled synthetic scenarios. They do not represent expected performance in real banking operations.
